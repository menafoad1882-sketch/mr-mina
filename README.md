# 🎓 نظام إدارة المدرس

موقع متكامل يساعد المدرس على إدارة الطلاب والحصص والامتحانات والحسابات، مع إرسال التقارير لأولياء الأمور على الواتساب والإيميل. الواجهة بالكامل باللغة العربية وتعمل على الموبايل والكمبيوتر.

---

## ✨ المميزات

| الميزة | الوصف |
|--------|-------|
| 🔐 **تسجيل دخول آمن** | حساب أدمن (يوزر + باسورد) مع **استرجاع كلمة المرور** بكود سري |
| 👥 **تسجيل الطلاب** | إضافة الطلاب بأرقامهم وأرقام أولياء الأمور، وتنظيمهم في مجموعات |
| 🎫 **كود + باسورد + QR لكل طالب** | لكل طالب كود وكلمة مرور لدخول الامتحان، وكارت QR للطباعة |
| 📷 **حضور بمسح QR** | صفحة ماسح بالكاميرا لتسجيل حضور الطالب فورًا (+ إدخال يدوي) |
| 📅 **الحضور والغياب والتأخير** | تسجيل حاضر / متأخر / غائب بضغطة زر |
| 📚 **متابعة الواجب** | تسجيل من عمل الواجب ومن لم يعمله |
| 💰 **حساب الحصة** | من دفع ومن لم يدفع والمبلغ، وحساب دخل الحصة تلقائيًا |
| ✍️ **قوالب رسائل قابلة للتعديل** | قوالب جاهزة (حضور/غياب/تأخير/واجب/درجات/مستوى) تعدّلها كما تحب |
| 💬 **رسائل واتساب** | إرسال لأولياء الأمور بروابط جاهزة (مجاني) **أو تلقائيًا عبر API** |
| 📝 **امتحانات إلكترونية** | دخول الطالب بكود+باسورد، تصحيح تلقائي، مؤقّت، وإرسال النتيجة لولي الأمر |
| 📄 **امتحانات ورقية** | إدخال درجات الامتحانات الورقية وإرسال نتائجها لأولياء الأمور |
| 📊 **مستوى الطالب** | حساب المستوى من الدرجات والحضور وإرساله لولي الأمر |
| 📈 **تقارير شهرية** | تقرير الدخل الشهري، تحميله Excel، أو إرساله بالإيميل |
| ☁️ **Supabase (اختياري)** | نسخ احتياطي سحابي حتى لا تضيع البيانات |
| ⚙️ **الإعدادات** | الحساب، بيانات المدرس، الإيميل، واتساب API، وSupabase |

## 🚀 طريقة التشغيل

```bash
cd teacher_app
pip3 install -r requirements.txt   # تثبيت المكتبات
python3 database.py                # تهيئة قاعدة البيانات (يظهر كود الاسترجاع)
python3 app.py                     # تشغيل الموقع
```
أو ببساطة: `bash run.sh`

ثم افتح المتصفح على: **http://127.0.0.1:5000**

### 🔑 أول تسجيل دخول
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`
- **غيّرهما فورًا** من صفحة الإعدادات > الحساب.
- **كود استرجاع كلمة المرور** يظهر في الطرفية عند أول تشغيل، وتقدر تشوفه من الإعدادات > الحساب — احفظه في مكان آمن.

> يبدأ الموقع ببيانات تجريبية (5 طلاب + مجموعتين) لتجربته بسرعة.

## 🎫 كود الطالب و QR

- كل طالب يُنشأ له تلقائيًا **كود دخول** و**كلمة مرور امتحان**.
- من صفحة الطالب أو صفحة «كروت QR» تقدر تطبع كارت لكل طالب فيه الـ QR والكود والباسورد.
- الطالب يستخدم:
  - **الكود** (أو مسح QR) لتسجيل حضوره في الحصة.
  - **الكود + كلمة المرور** لدخول الامتحان الإلكتروني.

## 💬 الواتساب — وضعان

1. **روابط جاهزة (الافتراضي، مجاني):** الموقع يجهّز الرسالة وتضغط زر يفتح واتساب، وانت بس تبعت.
2. **إرسال تلقائي عبر API (اختياري):** من الإعدادات > واتساب API، اختر مزودًا (UltraMsg / Meta / Twilio) واملأ البيانات — الرسائل تتبعت لوحدها بدون تدخل. (خدمة مدفوعة من المزوّد.)

---

## ☁️ Supabase (نسخ احتياطي سحابي)

التطبيق يشتغل محليًا بـ SQLite (سريع وبدون إنترنت). لتأمين البيانات في السحابة:
1. اعمل حساب مجاني على [supabase.com](https://supabase.com) وأنشئ مشروعًا.
2. من Settings > API، خذ الـ **URL** و **anon key**.
3. من الموقع: الإعدادات > Supabase، فعّلها وأدخل البيانات.
4. شغّل كود إنشاء الجداول (SQL معروض في نفس الصفحة) مرة واحدة في Supabase.
5. استخدم أزرار **رفع نسخة احتياطية** و**استرجاع** وقت ما تحب.

---

## 📧 إرسال التقارير بالإيميل (Gmail)

1. فعّل «التحقق بخطوتين» على حساب جوجل.
2. أنشئ **كلمة مرور التطبيقات (App Password)** واستخدمها في الإعدادات > الإيميل.
   - الخادم: `smtp.gmail.com` — المنفذ: `587`
3. من صفحة التقارير اضغط «إرسال بالإيميل».

## 🔒 ملاحظات أمان
- بيانات الطلاب في `teacher.db` محليًا ولا تُرفع على GitHub.
- لا تضع كلمات المرور/المفاتيح في الكود — اضبطها من صفحة الإعدادات.
- غيّر `app.secret_key` في `app.py` قبل النشر الحقيقي، واستخدم خادم إنتاج مثل `gunicorn`.
